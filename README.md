# SentenceLearner · 手敲练英文造句

看中文 → 手写英文 → 朗读听 → 提示/抄写 → 提交判分 → 复习。

一个**本地优先、零依赖**的英文造句刻意练习工具，专门针对「中文思维 → 英文输出」这个最薄弱、却最常用（写邮件、写汇报、开会发言）的能力做训练。灵感来自 Qwerty Learner 的「看中文默写英文」思路，但聚焦**写整句**而非背单词。

## 为什么需要它

背单词不等于会造句。真实工作里（比如给海外老板写周报、回邮件、开会发言）需要的是：看到中文意思，能立刻、准确地写出/说出英文句子。本工具把这件事拆成可重复、有反馈、有间隔复习的刻意练习。

## 功能特性

- **分级练习**：初级（≤15 词）/ 高级（>15 词）两档，内置 300+ 句（日常 / 商务 / 工控 / 邮件等主题）。
- **逐字符实时纠错**：写错立即标红并强制纠正，避免把错误写法练熟。
- **TTS 朗读**：美式 / 英式可选，语速 0.5×–1.5× 可调。**每开始练习一句，自动朗读一次**；想再听点「朗读」按钮即可。
- **渐进提示 / 显示答案**：按词逐步揭示原文，或直接显示整句供抄写。
- **即时正反馈**：写对自动提交并**撒花庆祝** + 明确文字反馈（正确 / 待核对）；写错显示答案与红色提示。
- **错句本**：写错、或用提示/答案才写出的句子自动进入，可「看原文」「重练」。
- **学习统计**：已练习次数、掌握率、待复习句数、平均 WPM，及难度分布 / 分类掌握率。
- **间隔重复复习**：轻量遗忘曲线（间隔 1/3/7/15/30/60/120 天），到期自动优先推送。
- **句型训练**：口头交流 / 商务邮件两方向，完整造句 + 句型填空双模式，进度自包含。
- **本地文件存储**：`serve.js` 把数据落盘到 `data/store.json`（原子写）；无服务时浏览器 `localStorage` 兜底，首次起服务自动迁移。
- **一键启动**：`start.bat`（Windows）/ `start.sh`（Mac·Linux）双击即用。

## 运行方式

**方式一（推荐，带本地存储）**：双击 `start.bat`（Windows）或 `start.sh`（Mac·Linux）。它会启动本地服务并自动打开浏览器到 `http://127.0.0.1:8787`。

**方式二（快速预览）**：直接用浏览器打开 `index.html`。此时数据仅存浏览器缓存（清站点数据会丢），右上角徽标会提示「浏览器缓存」。

**方式三（手动）**：
```bash
node serve.js
# 浏览器访问 http://127.0.0.1:8787
```

## 数据存储

- 有服务时：权威数据在 `data/store.json`（先写 `.tmp` 再 `rename`，防止写崩）。
- 无服务时：浏览器 `localStorage` 兜底；首次用 `start.*` 起服务会把缓存数据合并进文件。
- 存什么：错句本、收藏、练习日志、自定义句、间隔重复计划、句型进度。

## 快捷键（练习页）

- `L` 朗读 · `H` 提示 · `Enter` 提交 · `→` 下一题

## 技术说明

- **零依赖**：浏览器端纯原生 HTML/CSS/JS；`serve.js` 仅用 Node 内置模块（`http`/`fs`/`path`），无任何 npm 依赖、无 CDN。
- **为何零依赖**：目标环境无外网，npm/CDN 不可用；所有解析（xlsx）与存储均自实现。
- **浏览器要求**：TTS 依赖 Web Speech API，Chrome / Edge 体验最佳。
